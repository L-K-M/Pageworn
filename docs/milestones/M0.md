# M0 report: build and test baseline

Date: 21 November 2026. Target: the [M0 exit check](../06-delivery-and-tests.md#milestones) and the [M0 build and test baseline](../06-delivery-and-tests.md#m0-build-and-test-baseline).

## 1. Delivered

- An installable debug app with application ID `ch.lkmc.pageworn`, minimum SDK 34, compile and target SDK 37, and the adaptive launcher icon from `docs/art/icon/`. The app opens a placeholder activity; the screens arrive with M1.
- A Media3 library service plays a local edition as one book timeline: one media item per book over a concatenated source of its tracks. It plays the bundled chaptered M4B and the multi-file Boundary book. A seek to book time 115 s plays track B from 25 s. Headset Next and Previous move 30 s forward and 15 s back.
- The format matrix covers every extension that the Audiobookshelf v2.38.0 scanner admits, on the API 34 and API 37 emulators: [format-matrix.md](../format-matrix.md). The listener's families (M4B, M4A, MP3, FLAC, Opus, Ogg) are playable on both targets, with audible seek errors from -80 ms to +12 ms. AIFF, WMA, CAF, ALAC and MPEG-PS with MP2 are unsupported on both and are refused before download.
- CI builds the debug app and runs the JVM tests on every push and pull request, through `scripts/build.sh`.
- Reproducible synthetic fixtures (`fixtures/generate.py`, manifest in `fixtures/manifest.json`) and a local Audiobookshelf v2.38.0 reference instance with sanitized captures (`server-fixture/`, `app/src/test/resources/abs/v2.38.0/`).

## 2. Files and design decisions

- **Build.** Gradle 9.8.2 wrapper with a pinned checksum, AGP 9.5.2 with built-in Kotlin 2.4.21, KSP 2.3.14, a version catalog in `gradle/libs.versions.toml`. The Compose BOM stays at 2026.09.00 because Compose 1.13 requires compile SDK 37.1. The version name comes from `-Ppageworn.versionName` and the version code is `MAJOR*1000000 + MINOR*1000 + PATCH`, as `scripts/release-version.sh` computes it. Release signing reads the four `PAGEWORN_*` inputs from the environment, and `verifyReleaseSigning` names any missing input before a release build starts.
- **Timeline core** (`core/timeline/`). `BookTimeline` maps book time to track and offset and back, and divides an edition by chapters, tracks or the whole book. `ChapterMapBuilder` validates server chapters, falls back to embedded markers and generates Opening and Interlude segments. `ResumeRewind` decides the start position after a rest. All three are pure Kotlin with JVM tests.
- **Playback** (`playback/`). `BookMediaSourceFactory` resolves a book item to a `ConcatenatingMediaSource2`. `ExactMp3ExtractorsFactory` gives local MP3 files an exact frame index, because Media3 1.11.1 interpolates a VBR file's Xing table and missed late seeks in the 21-minute fixture by 1.4 s. `CommandAdjustingListener` corrects the forwarding player's command events, so controllers see Next and Previous. `PlaybackService` and `BookSessionCallback` serve the session and the library tree.
- **Data** (`data/`). Room schema v1 (`app/schemas/`), progress writes ordered by playback generation and write sequence, and edition staging, publication and recovery. M3 and M4 exercise these; M0 only builds them.
- **Formats** (`formats/`). `MediaProbe` reads a local track's container and codec. `FormatSupport` applies the matrix and the phone's decoder list.
- **Plan changes in this milestone.**
  - [Playback and formats](../05-playback-and-formats.md): the timeline uses the probed durations as contiguous tracks. A chapter gap or overlap of up to 5 ms is rounding noise. MP3 seeking uses the exact frame index. A server chapter list that only restates the tracks counts as no markers, because Audiobookshelf v2.38.0 generates one chapter per file for a multi-file book without marks.
  - [Android and data](../03-android-and-data.md): the app backs up nothing.
  - [Server contract](../04-server-and-downloads.md#observed-on-the-reference-instance): the observations from the reference instance.
  - [Format matrix](../format-matrix.md): the record and its method.
