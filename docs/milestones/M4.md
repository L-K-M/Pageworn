# M4 report: full playback integration

Target: [M4](../06-delivery-and-tests.md#milestones), using the API 34 and API 37 Pixel 7 Google APIs arm64 emulators from [M0](M0.md#3-builds-tests-and-targets), Media3 1.11.1 and the local Audiobookshelf v2.38.0 reference instance.

## Delivered

- Downloads import supported embedded chapter markers only when the server supplies no usable chapter list. The file probe requires a decodable audio track. The [format matrix](../format-matrix.md) records audible seeks, decoder support and chapter sources for both emulator images.
- Playback pauses and preserves the listener’s place when a track fails to open or read. Repair replaces the affected edition only after verification. A shortened track is detected before playback. Play during an in-flight seek keeps the new target, and a seek to the end marks the book finished.
- Player, mini-player, Downloaded, Library and details name the available Play, Resume, Replay or Pause action. Chapters, track lists, skips, scrubbing and speed were exercised through the player UI.
- The system media session exposes whole-book skips and the ready-book car list. A media key can resume the saved book and speed after a background process kill. Download completion is a separate notification and opens Downloaded. Downloads and the playback session remain usable when notifications are denied.
