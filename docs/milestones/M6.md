- Settings opens the generated notices for the runtime dependencies and the bundled Spectral font. The release variant generates its own list from the Gradle classpath.
- Export diagnostics opens the system create-document picker. The text includes the app version, Android version, and a bounded in-memory record of network operations. It uses address labels and fixed operation and outcome categories. A label that contains the address host or URL punctuation is replaced.
