# Follow-up report: home screen widgets

Date: 22 November 2026. Target: the owner's request for Android widgets, added to the scope after the milestones. The plan changed in the same commits.

The first evidence came from JVM, Robolectric, build and source checks. The same evening the widgets ran on a real launcher on two emulators, as [section 3a](#3a-on-a-launcher-the-same-evening) records. No phone ran them.

## 1. Delivered

| Widget | Behavior |
|---|---|
| Now reading | The player's book with its cover. By size, it adds the title and chapter, both progress bars, the 15 and 30 second skips, the author and the times. A tap beside the keys opens the player, or the book's details when the player has no book. |
| Bookshelf | Up to four books, newest download first, each with Play or Pause. A cover opens that book's details. A book that cannot play shows Repair or Choose. Playing does not reorder the shelf. |

Both follow day, night and the font scale, name their keys for TalkBack, say why a book did not start and ask to stay off the lock screen.

Choices the request left open, now in the [interface specification](../02-interface.md#home-screen-widgets):

- There are two widgets in the app's paper and cloth, with no settings of their own.
- Without a loaded or last-played book, Now reading shows the first book of Downloaded.
- While a book plays, the chapter bar moves every 30 seconds and the book bar every minute. There are no running clocks.
- Where both sentences of a failed start do not fit, the widget shows the first and reads out both.

Two defects in existing code were fixed on the way: a repeated Open player link did nothing (`3a68dba`), and a skip for one book could move another that was starting (`0435469`).

## 2. Files and design decisions

- `widget/WidgetStates.kt` holds the pure rules, `WidgetViews.kt` and `WidgetCovers.kt` draw them as RemoteViews, and `HomeWidgets.kt` publishes them and carries out taps. There is no new dependency.
- A key is an immutable, explicit foreground broadcast to an unexported receiver and names its book. `playback/BookTransport.kt` now serves both the player screen and the widgets.
- `playback/PlayerConnection.kt` applies a skip after any handover in progress, so it moves the book it names.
- A widget tap needs no second service on Android 17. [Playback and formats](../05-playback-and-formats.md) records the path through the platform source. A32b on the API 37 emulator then observed it, as section 3a records.
- The launcher receives one set of cover bitmaps for all arrangements. Live text uses the system serif, because a launcher cannot load the bundled Spectral.
- Plan: the README, documents 01, 02, 03, 05, 06 and 08, with new cases A32, A32b and V07 and an owner check.

## 4. Failing and unrun cases

**Failed once.** In one of the clean builds of `4928250`, on a loaded machine:

- `TransferCoordinatorTest#pause_duringCopyKeepsPartialAndYieldsSlot`. The test releases the copy as soon as Paused is saved, which can precede the cancellation. To reproduce on `6368e08`, from before the widgets, add `delay(300)` before `stopRun` in `TransferCoordinator.pause`: the test then finds all 131,072 bytes copied where it expects fewer. `b2435ac` makes both tests that release a paused copy wait until it is cancelling.
- `NetworkDiagnosticsTest#successfulRequestRecordsLabelOperationAndCategoryOnly`. The cause is unverified and did not reproduce. Its code and test predate the widgets.

Neither failed again in ten targeted runs, four full suites or six clean builds. The network test is unchanged.

**Failing outside the configured test targets.** Forced to Robolectric API 37, the three `OpenPlayerIntentTest` cases stop in the Compose test tools (`InputManager.getInstance()` is absent), and `WidgetViewsTest#aFullShelfStaysFarInsideTheLaunchersPictureLimit` casts a platform value that API 37 returns as a Long. CI runs these on API 34. To reproduce, set those classes' `@Config` to `sdk = [37]`.

**Not run, or run in part.**

| IDs | Open part | Reason and reproduction |
|---|---|---|
| A32b | The swipe out of Recents on API 37, and audible sound | The swipe gesture did not remove the task. The emulators had no audio output, so sound was checked as a started, unmuted player. |
| V07 | Spoken TalkBack, the least sizes on API 31 and the exact least sizes | No listener for speech. Launchers size in cells, and Robolectric covers the least sizes. |
| A31 | Install, sign in, download and play 1.3.0 | Signing in would have typed the disposable password outside an instrumentation argument. M6 ran it for 1.2.3. |
| A10d on API 31 | With audio output | It passed without audio output and failed with it before. |
| Instrumented cases with host phases | M2 to M5 server and restart phases | As in the [owner-notes report](owner-notes-2026-11-22.md#4-failing-and-unrun-cases) |

Every other open or unrun case is unchanged from the [owner-notes report](owner-notes-2026-11-22.md#4-failing-and-unrun-cases).

Known limits:

- Below 157 dp of height, more with large type, Now reading has no skips.
- The compact arrangement cannot enlarge its notice at 200% text. Long titles, and the book line at 200%, end in an ellipsis.
- Picker previews show plain cloth covers. The high-contrast setting does not reach the widgets.
- If Android kills the process during playback, a widget can show Pause until it is tapped.
- A skip can wait up to five seconds during a book switch that another controller started. A Pause during such a switch can pause the new book.
- Older Android versions may ignore the request to stay off the lock screen, and launchers differ in sizing.
