## [Unreleased]

### Added

- Android audiobook player for one listener's Audiobookshelf library, with
  library selection, remote catalog browsing, downloaded-book shelves, book
  details, Android Auto browsing, and a custom player interface.
- Durable offline catalog publication and resumable edition transfers with
  integrity validation, cancellation, removal, repair, and recovery behavior.
- Playback with chapter-aware progress, rewinds, exact sleep-timer stops,
  system media controls, notification handling, playback-speed controls, and
  interruption recovery.
- Interface polish including cover grids, large-text layouts, press feedback,
  optional interface sounds, and an in-app dependency and asset license list.
- Project tooling: reproducible Gradle build and release scripts, CI and
  tag-triggered signed-release workflows, Dependabot, the GLM/StepFun review
  workflow, and agent instructions.
